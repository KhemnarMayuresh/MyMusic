# For you design — approved conversation scope

Add an enabled-by-default For you tab before Songs; Songs remains the launch default. Use local per-song play count/last-played time and per-song/month counters, not event logs or audio copies. Keep recommendation records separate from existing Recently Played history. Disabling hides the tab and stops recommendation writes without clearing records. Explicit Settings cleanup requires confirmation and clears recommendation counters only. No automatic pruning; retained records remain until cleanup.

Show Top picks, Recently Played, Explore your library (Top Artist mix, Daily discover, Never Played, Before 1980, Before 2000, High Quality), and the current month's top chart. Every mix opens a playable song list; individual tracks, Play and Shuffle use existing playback. Missing year/bitrate stays unknown. Lossless MIME types or bitrate >=320000 qualify for High Quality. Hidden/filtered/deleted tracks never enter recommendations. Empty sections explain how to populate them.

SQLite v1 -> v2 adds two small aggregate tables without changing existing tables/data. The enabled preference is checked under the repository transaction lock. Storage is not included in existing backup format in this iteration; existing backup compatibility remains. Package my.music, version 1.0.0; no dependencies, ads, accounts or network access.
